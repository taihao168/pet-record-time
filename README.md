# 🐶 บันทึกการขับถ่ายของน้องหมา

เว็บแอปสำหรับบันทึกเวลาที่สุนัขฉี่และอึ ใช้งานง่ายบนมือถือ ทำงานแบบออฟไลน์ได้ ไม่ต้องต่ออินเทอร์เน็ต และไม่ส่งข้อมูลออกนอกเครื่อง

## ความสามารถ

- 💛 / 💩 แตะปุ่มเดียวเพื่อบันทึกเวลาฉี่หรืออึทันที
- 📊 สรุปจำนวนครั้งของวันนี้ และเวลาที่ขับถ่ายล่าสุด
- 🕓 ดูประวัติย้อนหลัง พร้อมเวลาที่ผ่านมา (เช่น "20 นาทีก่อน")
- ✏️ เพิ่มบันทึกย้อนหลังได้ พร้อมโน้ต (เช่น สี, สถานที่)
- 📤 ส่งออกข้อมูลเป็นไฟล์ CSV เพื่อเก็บหรือส่งให้สัตวแพทย์
- 📱 ติดตั้งเป็นแอปบนหน้าจอหลักได้ (PWA) และใช้ออฟไลน์
- 🌙 รองรับโหมดมืดอัตโนมัติ

## วิธีใช้

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย หรือเปิดผ่านเว็บเซิร์ฟเวอร์:

```bash
# ตัวอย่างเปิดด้วย Python
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

บนมือถือ เมื่อเปิดผ่าน HTTPS หรือ localhost สามารถกด "เพิ่มไปยังหน้าจอหลัก" เพื่อติดตั้งเป็นแอปได้

## การเก็บข้อมูล

ข้อมูลทั้งหมดถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์บนเครื่องของคุณเท่านั้น
ไม่มีการส่งข้อมูลไปยังเซิร์ฟเวอร์ใด ๆ ควรส่งออก CSV เป็นระยะเพื่อสำรองข้อมูล

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|------|--------|
| `index.html` | ตัวแอปทั้งหมด (HTML/CSS/JS ในไฟล์เดียว) |
| `manifest.json` | ข้อมูล PWA สำหรับติดตั้งเป็นแอป |
| `sw.js` | Service Worker สำหรับใช้งานออฟไลน์ |
